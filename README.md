## 🎵 1. Cloud Music Player (云音乐)

> 一个现代化的网页音乐播放器，采用 Glassmorphism 设计风格。

* **核心功能**：支持网易云/QQ/酷我多源搜索、热歌榜、LRC 歌词实时滚动、无损音质下载。
* **交互体验**：全屏沉浸式模式，支持键盘快捷键，移动端完美适配。

## 🎬 2. Video Parser (全网视频解析)

> 简洁高效的视频在线解析工具，解决跨平台观影需求。

## 🚀 快速开始 (Getting Started)

本仓库所有项目均为 **纯静态页面**，无需安装 Node.js 环境。

1.  **克隆仓库**
    
    ```bash
    git clone https://github.com/Lansewenzi/Portfolio.git
    ```
    
2.  **运行项目**
    * **音乐播放器**：进入 `music` 文件夹，打开 `index.html`。
    * **视频解析**：进入 `video` 文件夹，打开 `index.html`。
